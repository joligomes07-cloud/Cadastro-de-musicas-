# Cadastro-de-musicas-
Sistema de catálogo de músicas desenvolvido em Python, com funcionalidades de cadastro, listagem e exclusão de músicas utilizando persistência em arquivos de texto

Sistema desenvolvido em Python para cadastro de músicas utilizando arquivos texto.

## Funcionalidades

- Cadastrar músicas
- Listar músicas
- Excluir músicas
- Geração automática de código para cada música

## Tecnologia

- Python 3

## Como executar

```bash
python main.py
